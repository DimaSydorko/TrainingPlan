**Gaps in the seams that Phase 1 must resolve.** If a signature changes, update README §6 and all callers in the same commit.
- `SoundPlayer` has no `setVolume` or `getDuration`. The old code used both. The `setVolume` call sites now have TODO comments, so sound plays at default volume for now. The post-cue speech delay uses the new `SOUND_CUE_DURATION_MS = 1000` constant, appended to `app/Utils/constants.ts`. A3 probably needs `createSoundPlayer(type, { volume })` or a `setVolume` method, and either a duration or a promise from `play()`. Agree this with A4.
- `useTTS`: the old Moira iOS voice and the Android pan/stream params are kept only in a TODO comment.
- Audio category: the module-level `Sound.setCategory('Playback', true)` in `usePlaying` is now `configureAudioSession({ duckOthers: false })`. The `setCategory` calls in Settings (`'Playback'`) and the sound picker (`'Alarm'`) were removed; the picker's has a TODO.
- `signOutGoogle()` replaces `revokeAccess()` + `signOut()`, and `getGoogleIdToken()` replaces `hasPlayServices` + `signIn`. Both moved into the seam (see its header comment).
- `AppGoogleSignInButton` renders the app's `ConfirmButton` ("Sign in with Google") instead of `GoogleSigninButton`.
- `BackgroundAction` no longer runs the 1-second keep-alive loop. `linkingURI 'yourSchemeHere://chat/jane'` and the `ic_launcher` icon are gone; they are noted in a TODO(A4).

## Deviations from the brief
1. **No device boot (task 7).** The container has no Android SDK, Xcode or emulator. In its place, these pass: `tsc`, `expo prebuild --clean --no-install`, and `expo export` for android and ios. Email login and tab rendering have **not** been verified on a device.
2. **iOS bundle ID.** D1 (`com.trainingplantogether_cli`) is invalid for Apple because of the underscore, so `com.trainingplantogether-cli` is used for now. This is an open question for Dmytro in DECISIONS.md.
3. **`@react-native-google-signin/google-signin` plugin is commented out, not declared.** The package is uninstalled in Phase 0, and declaring a plugin for a missing package breaks prebuild. A2 enables it.
4. **`expo-audio` and `expo-notifications` are installed now,** not only declared, so that their plugins resolve. A3 and A4 configure them.
5. **`npm test` is a placeholder** (`echo … && exit 0`), because the brief removes `jest` and A7 adds `jest-expo`.
6. **Extra upgrades the brief didn't list,** all needed to install or boot: `redux` 5, `react-native-draggable-flatlist` 4, `expo-asset`, `expo-system-ui`, `@expo/vector-icons` + `expo-font`. `@types/react-redux` was removed.
7. **`app/env.d.ts`** references only `expo/types/metro-require`, not all of `expo/types`. Expo's react-native-web style augmentation clashes with RN 0.86 types in `Parents.tsx`, `Approach.tsx` and `PlayHeader.tsx` (13 errors). `tsconfig.json` doesn't include the generated `expo-env.d.ts`.
8. **`package.json` and `package-lock.json` were edited by hand once.** Dropping the old libraries and setting the new majors by hand, followed by a fresh `npm install`, was the only way past the npm peer-dependency deadlock between React 17-era and React 19 packages. Everything after that went through `npm` / `expo install`.
9. **`expo install` was run with `EXPO_OFFLINE=1`** because `api.expo.dev` is blocked; versions came from `expo/bundledNativeModules.json`.

## Requests to other agents
- **A1:**
  - Compat auth has no React Native persistence (it uses the browser build, so in-memory only). Users are logged out on every app restart until you move to the modular API with `getReactNativePersistence(AsyncStorage)`.
  - Without a `.env`, `firebase.initializeApp` gets `undefined` values and the app will fail at startup with `auth/invalid-api-key`. Dmytro needs a real `.env`.
- **A2:**
  - Old release builds were signed with the **debug keystore** (`android/app/build.gradle` `signingConfigs.debug`, now deleted; still in git history at ee75ad7). Find out from Dmytro which keystore signed the Play Store build before configuring EAS credentials.
  - The old `google-services.json` was removed with `android/` and is still in history; it isn't needed with the JS SDK (D2).
  - Old manifest permissions: INTERNET, VIBRATE, FOREGROUND_SERVICE, WAKE_LOCK. The current prebuild adds FOREGROUND_SERVICE + FOREGROUND_SERVICE_MEDIA_PLAYBACK + MODIFY_AUDIO_SETTINGS (expo-audio defaults) and READ/WRITE_EXTERNAL_STORAGE + SYSTEM_ALERT_WINDOW (Expo defaults). Consider `blockedPermissions`.
  - iOS gets `UIBackgroundModes: [audio]` from expo-audio's default `enableBackgroundPlayback: true`. Decide with A3/A4 whether to keep it.
  - Scheme `trainingplan` and app name "Training Plan" (from the old Android `app_name`); slug `training-plan`.
- **A3:** resolve the `SoundPlayer` volume and duration gap (see above). The sounds are in `app/Assets/sounds/`; `SoundType` values are the mp3 file names (`app/Utils/constants.ts`).
- **A4:** `BackgroundAction.tsx` passes `progress: { value: 100, max: 100 }` on start, the same as the old code, and then `{ value: playTimer, max: duration }`.
- **A5:**
  - 7 `@ts-expect-error TODO(A5)` markers.
  - React Navigation 7 behaviour changes such as `navigate` semantics weren't checked, because nothing could be run.
  - Old JS libraries on the boot path still use deprecated APIs and are unverified at runtime: `react-native-keyboard-aware-scroll-view` (findNodeHandle, Login screen), `react-native-scroll-picker-wheel`, and `react-native-circular-progress` (prop-types).
- **A7:** `jest`, `babel-jest` and `react-test-renderer` were removed. `__tests__/App-test.js` still imports `react-test-renderer`.
